Соединительные элементы МС для колодцев: виды и подбор по проекту

Соединительные элементы МС — железобетонные изделия, предусмотренные типовыми проектами для сопряжения сборных элементов колодцев. В каталоге представлены марки МС-1—МС-8. Для правильного заказа важно сверить не только номер марки, но и проектный комплект, лист чертежа и спецификацию.

Главное правило: подбирайте соединительный элемент по рабочей документации конкретного сооружения. Номер МС сам по себе не определяет допустимую нагрузку, тип грунта или универсальную область применения.

1. В каких проектах есть соединительные элементы МС

В каталоге указываются два комплекта типовой проектной документации:

  • Типовые проектные решения 901-09-11.84. Колодцы водопроводные. Альбом VI.88. Дополнительные мероприятия для строительства в сейсмических районах (7–9 баллов). Проект для водопроводных колодцев.
  • Типовые проектные решения 902-09-22.84. Колодцы канализационные. Альбом VIII.88. Дополнительные мероприятия для строительства в сейсмических районах (7–9 баллов). Проект для канализационных колодцев.

В обоих комплектах присутствуют чертежи соединительных элементов МС. При этом при работе с конкретным объектом нужно пользоваться соответствующим проекту альбомом и сверять марку, лист и спецификацию. Наличие одинаковой номенклатуры не означает, что можно игнорировать проектные условия.

Материалы для ознакомления: скан альбома VI.88 ТПР 901 и описание альбома VIII.88 ТПР 902.

3. Как выбрать нужную марку

  1. Определите тип сооружения и используемый типовой проект.
  2. Найдите в альбоме чертёж соединительных элементов и схему их расположения.
  3. Сверьте обозначение МС на чертеже с позицией в спецификации.
  4. Проверьте размеры и массу по документации и каталогу.
  5. Уточните количество и место установки по проектному узлу.

Не следует назначать МС-2—МС-8 для «повышенных нагрузок», особых грунтов или специальных условий только по возрастанию номера. Такие характеристики должны быть прямо подтверждены проектом.

4. Описание и монтаж

МС — соединительный элемент. Его конкретное положение относительно колец, плиты перекрытия или днищевой плиты, количество на один узел и конструктивные детали монтажа определяются чертежом и спецификацией соответствующего альбома.

Перед установкой проверьте марку изделия, размеры, количество, расположение и соответствие проектному узлу. Не заменяйте один типоразмер другим и не выбирайте способ крепления по общему описанию: монтаж выполняют по рабочей документации объекта.

5. Какие документы нужны для подбора

  • лист чертежа с обозначением соединительного элемента;
  • спецификация или ведомость расхода элементов;
  • обозначение типового проекта и альбома;
  • при наличии — рабочий чертёж конкретного колодца.

Если нужная марка или количество неочевидны, направьте чертёж и спецификацию специалисту до оформления заказа.

6. Частые ошибки

  • выбирать марку только по её номеру;
  • считать два проектных альбома полностью взаимозаменяемыми;
  • назначать количество без проверки схемы расположения;
  • переносить монтажный узел с одного проекта на другой;
  • подменять отсутствующий чертёж общим описанием товара.

Частые вопросы

Все ли МС-1—МС-8 есть в наличии?

Да, по информации производителя, все восемь марок есть в наличии. Актуальную цену и количество можно уточнить при заказе.

Почему указаны два альбома?

Соединительные элементы МС представлены в ТПР 901 для водопроводных колодцев и ТПР 902 для канализационных колодцев. При подборе важно сверять проект конкретного объекта.

Где посмотреть фотографии и чертежи самих изделий?

Фотографии изделий находятся в работе. До получения подтверждённых изображений в карточках используется заглушка; вымышленные изображения и неподтверждённые схемы не публикуются.
