1. Вкладка HTML: содержимое файла video-page-html.html
2. Вкладка CSS: содержимое файла video-page-styles.css
3. Вкладка JS: содержимое файла video-page-scripts.js
4. Вкладка CDN: подключить библиотеку:

Важно:
- Не вставлять в HTML теги <html>, <head>, <body>, <style> или <script>: разметка уже подготовлена для поля HTML.
- CSS вынесен отдельно; JS вынесен отдельно.
- Системный адаптивный скрипт Creatium, который использует document.write, намеренно не переносится: его обеспечивает сама платформа.
- jQuery и API cr должны предоставляться Creatium.
- Это тестовая сборка. После вставки нужно проверить предпросмотр; формы, меню и всплывающий блок могут потребовать дополнительной адаптации к HTML-секции.
